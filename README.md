# Hyprland + Serpantinum Desktop Dotfiles

Полная резервная копия конфигурации рабочего стола и скрипт автоматической установки для Arch Linux.

## Содержимое репозитория

* `config/` — пользовательские конфигурации (`~/.config`):
  * `hypr/` — настройки оконного менеджера Hyprland (горячие клавиши, мониторы, анимации, правила окон, переменные окружения с аппаратным ускорением NVIDIA).
  * `serpantinum/` — настройки интерфейса Serpantinum / Quickshell (тема, панель задач, виджеты).
  * `kitty/` — конфигурация терминала Kitty.
  * `environment.d/` — системные переменные окружения.
  * `gamemode.ini` — профиль GameMode для максимальной производительности GPU и CPU в играх.
  * `cava/`, `fastfetch/`, `gtk-3.0/`, `gtk-4.0/`, `xsettingsd/`, `gammastep/`.
* `local_share/serpantinum/` — полный исходный код оболочки рабочего стола Serpantinum (включая исправление скрытия закрытых приложений с панели задач).
* `local_bin/` — полезные системные утилиты и скрипты:
  * `fan` (`low`, `balanced`, `boost`) — переключение режимов работы кулеров и производительности.
  * `Ram` — быстрая очистка оперативной памяти и сброс системного кэша.
  * `sync-papirus-folder-color.py` — синхронизация цветов папок Papirus с акцентным цветом темы.
  * `quickshell-share-picker` — интерфейс выбора экрана/окна для захвата видео и демонстрации экрана.
* `packages-repo.txt` — список официальных пакетов Arch Linux.
* `packages-aur.txt` — список пакетов из AUR (устанавливаются через `yay`).
* `optimize-system.sh` — системные твики (NVMe noatime, NVIDIA persistenced, TCP BBR, сетевые буферы).
* `install.sh` — единый установочный скрипт.

---

## Установка и восстановление

Для восстановления окружения на чистой системе Arch Linux или применения настроек выполните:

```bash
cd ~/dotfiles
./install.sh
```

Скрипт автоматически:
1. Предложит установить официальные пакеты через `pacman`.
2. Проверит наличие `yay` и при необходимости установит его, а затем установит AUR-пакеты.
3. Создаст резервную копию существующих конфигураций в `~/.config_backup_*`.
4. Развернет все конфигурации в `~/.config/`, `~/.local/share/` и `~/.local/bin/`.
5. Настроит симлинки команд и алиасы в `~/.bashrc`.
6. Предложит применить системную оптимизацию оборудования (CPU, GPU, NVMe).
